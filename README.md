# عدسة | Adasa

واجهة مدونة عربية عن التصوير الفوتوغرافي مبنية باستخدام React وVite.

## الصفحات

- `/` الصفحة الرئيسية
- `/blog` قائمة المقالات مع البحث، الفلترة، الترقيم، وتبديل Grid/List
- `/blog/:postId` تفاصيل المقال
- أي مسار غير معروف يعرض صفحة 404

## التشغيل

```bash
npm install
npm run dev
```

لإنشاء نسخة production:

```bash
npm run build
```
